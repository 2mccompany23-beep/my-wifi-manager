### 4. Fiche Réflexe : Résoudre les 3 Blocages Fréquents 🛠️

#### 🛑 Blocage 1 : « Je n'ai pas reçu le code par e-mail ! »
- **Cause :** Les serveurs de vote envoient des milliers de mails en même temps ; Gmail et Outlook classent souvent le mail en courrier indésirable.
- **Réflexe Agent :** 
  1. Dites calmement : *"Ne fermez pas la page !"*
  2. Ouvrez l'application Gmail ou Outlook de l'étudiant.
  3. Cliquez sur le menu ☰ en haut à gauche ➔ Sélectionnez le dossier **Spam** (ou **Courrier indésirable**).
  4. Le mail s'y trouve à 99%. Relevez le code à 6 chiffres et entrez-le sur la page ouverte.

#### 🛑 Blocage 2 : « J'ai un iPhone et la page s'est fermée quand j'ai ouvert mes mails ! »
- **Cause :** Sur iPhone, la mini-fenêtre du Wi-Fi se referme si l'utilisateur change d'application.
- **Réflexe Agent :** 
  - Ouvrez l'application **Safari** de l'étudiant.
  - Tapez simplement dans la barre d'adresse : **`vote.bj`**
  - La page officielle de vote s'ouvre dans Safari et **ne se fermera plus jamais**, même s'il bascule sur sa boîte mail.

#### 🛑 Blocage 3 : « Le Wi-Fi me dit 'Connecté sans Internet' »
- **Cause :** Le câble entre la Box 4G et le routeur est mal enclenché ou la Box 4G n'a plus de forfait.
- **Réflexe Agent :**
  - Vérifiez que le câble est bien sur le port **`ether1`** (pas ether2 ni ether3).
  - Vérifiez les voyants de la Box 4G.
  - Débranchez et rebranchez l'alimentation du routeur (redémarrage en 20 secondes).
